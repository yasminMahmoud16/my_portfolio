## About

This portfolio website is designed to showcase my projects, skills, and contact information. It is fully responsive and has light/dark theme support. The website also features interactive animations using **Framer Motion** and smooth navigation.

---

## Technologies Used

- **React** – Frontend library
- **Tailwind CSS** – Utility-first CSS framework
- **Ant Design** – UI components and icons
- **Framer Motion** – Animations

---

## Features

- Responsive design for desktop, tablet, and mobile
- Dark/Light theme toggle
- Projects showcase with live demo and repository links
- Interactive buttons and hover effects
- Skills section with libraries and programming languages
- Contact section with social media links
